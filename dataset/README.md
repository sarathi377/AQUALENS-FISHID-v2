# Fish Species Dataset

This folder contains the dataset used and referenced in the "Fish Species Identification and Marine Analysis Using Gemini" research paper.

## Contents

- `fish_species.json`: A structured database of 24 distinct fish species. Each entry includes:
  - **ID**: Unique identifier.
  - **Name**: Multilingual names (English, Hindi, Marathi, Tamil, Telugu, Bengali, Malayalam).
  - **Scientific Name**: Latin nomenclature.
  - **Description**: Brief overview of the species.
  - **Habitat**: Typical environments where the species is found.
  - **Category**: Classification (Saltwater, Freshwater, Brackish).

## Purpose

The dataset is used by the Gemini 2.5 Flash model for contextual reasoning, few-shot classification, and providing detailed species-specific information to users. It supports the application's core identification and encyclopedia modules.

## Species Count
Total verified species: **24**
